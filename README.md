# 音声入力プロトタイプ

## 目的

既存のGASタスク管理本体を触らずに、iPhone/Safariでマイク取得と録音が成立するかだけを確認する。

## 設計根拠

- `getUserMedia()` はHTTPSの安全なコンテキストでマイク利用許可を要求するWeb標準。
- Apps Script HTMLServiceの埋め込み制約とは切り離し、最上位のHTTPSページとして試す。
- 本番接続前に、マイク取得 → 録音 → 再生の単体テストを通す。
- この段階ではOpenAI API、GAS、スプレッドシート、Slackへ送信しない。

## 本体への影響

なし。この公開用リポジトリは音声テスト専用で、現在のWebアプリ、17列履歴、期限・繰り返し、Slack通知、AI整理には影響しない。

## 次段階

1. GitHub PagesでHTTPS公開し、iPhone実機でマイク許可・録音・再生を確認。
2. 成立後に、OpenAI Realtime/WebRTCまたは音声文字起こし用の安全なサーバー経路を追加する。
3. APIキーはブラウザへ置かない。サーバー側で短命な認証情報を発行する。
4. 文字起こし結果だけを既存のAI整理へ渡す。
5. 本体接続後も17列構造は変更しない。

## 受入条件

- iPhone Safariでマイク許可ダイアログが出る。
- 録音開始/停止ができる。
- 録音した音声を同じ端末で再生できる。
- 現行GAS Webアプリの挙動が変わらない。
